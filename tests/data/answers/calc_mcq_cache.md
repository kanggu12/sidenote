ANSWER: ② 6ns
ASKED: 캐시 적중 시간이 1ns, 미스 패널티가 100ns, 적중률이 95%일 때 평균 메모리 접근 시간은?

평균 메모리 접근 시간은 적중 시간에 미스율과 미스 패널티의 곱을 더한 값입니다.

AMAT = 1ns + 0.05 × 100ns = 6ns 이므로 정답은 ②입니다.

적중률이 조금만 달라져도 값이 크게 바뀝니다. 적중률이 90%이면 11ns가 되고, 80%이면 21ns가 됩니다. 그래서 적중률을 올리는 일이 적중 시간을 줄이는 일보다 효과가 큰 경우가 많습니다.

① 5ns 는 적중 시간을 더하지 않은 값이고, ③ 11ns 는 적중률을 90%로 계산한 값이며, ④ 96ns 는 적중률과 미스율을 뒤바꾼 값입니다.
