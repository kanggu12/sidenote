ASKED: 다음 자바 코드의 출력은?

코드는 문자열을 `==` 로 비교합니다. 문자열 상수는 같은 객체를 가리키지만 `new` 로 만든 문자열은 다른 객체입니다.

1. **첫 번째 비교**: 두 상수는 같은 객체이므로 `true` 입니다.
2. **두 번째 비교**: `new String` 은 새 객체이므로 `false` 입니다.
3. **세 번째 비교**: `equals` 는 내용을 비교하므로 `true` 입니다.

보기를 따져 보면 다음과 같습니다.

- ① 은 두 번째 비교를 `true` 로 본 경우입니다.
- ② 는 세 비교의 결과가 모두 맞습니다.
- ③ 은 세 번째 비교를 `false` 로 본 경우입니다.

따라서 정답은 ②입니다.
